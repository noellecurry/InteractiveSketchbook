I want to make my interface as simple and user friendly as possible while still maintaining a design that looks good. I did two verisons for the laptop interface because I am still deciding on how I want my hamburger menu positioned. The first interface just shows off the hamburger icon, but I was thinking of a very simple drop-down navigation that will display all my pages. The second laptop interface shows a larger menu that I was thinking would only appear if user hovers over hamburger menu, so it is not always being displayed. In this menu, I have the title of the website within it and navigation that is in sections for each week of sketches. Then I have my phone interface that I am struggling with the most, I want it to only display what is neccesary but I am having trouble with how the menu should look. I do think this is a good start to what I had before because during my interface audit I realized how much my navigation is not user friendly and is very confusing. I want to make all my pages feel very consistent, and users do not have to guess when navigating through my website. By making it more consistent, I believe users will have more confidence and freedom to really explore which is the whole point of my website, a passive experience meant to enjoy. However, through that thinking I think that it is important to design for all devices and users to make sure I am consistent with my website and think about the heuristics my current website violates (number 3: user control and freedom and number 5: error preventions).
