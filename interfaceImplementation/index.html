Interface Implementation — Progress Snapshot

implementation screenshot

I am currently implementing the layout of all the text on my micro project page. I believe the visual hierarchy is working very well, and I also like the font that I choose for legibility. I am not done with implementing all the structural changes from my wireframe; I still need to work on spacing, especially with the button. I believe that my Figma logic does hold up well, and my design is very simple but is still interesting for the viewer. The aspect that breaks is my instructions, initially when doing my wireframe I felt that instructions were not needed. However, I forgot during my audit that I needed to implement a signifier to let users know of the auditory aspect. What surprised me was that it was easier than I thought to have the “interactive sketchbook” display as vertical on the page. I did have to get some from the internet but luckily it was only one line of code needed. Something that I am finding challenging is getting the font size and spacing between text to look right. Some assumptions that the browsers exposed are how much negative space is important for my design. Because my design is minimal, it is important to get the sizing and spacing right to make the flow of the text that is there. I also feel the same way when thinking about what the CSS assumes about flow. I will continue working on this CSS flow before final submission, and I also be working on having simple instructions or alert that there is audio. I always will need to start the mobile version as well but I believe once I finish off the desktop version it will be a fast process with the mobile version. My plan for the final week is: finish off the layout of the CSS and make sure the layout looks right, do the instructions/alert for the audio, and then start mobile.
